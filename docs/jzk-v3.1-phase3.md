# 九州康 JZK V3.1 第三批小程序

本分支叠加在 `feat/jzk-v3.1-phase2-business` 之上。

已接入：

- 个人经营中心中的库存盘点；
- 个人经营中心中的健康周报月报；
- 异常收货 V2 分 SKU 处理进度；
- 微信官方小程序码与私有文件下载；
- 业务中心和健康中心真实入口；
- 业务状态与提现状态订阅消息主动授权。

订阅授权边界：

- 业务中心“消息提醒”只在后端微信能力、订阅发送和真实模板均就绪时调用微信授权；
- 单次业务场景最多申请三个模板；
- 提现页在用户点击提交后、真实申请前，自愿申请一条提现状态模板；
- 用户拒绝授权或授权接口失败不会阻断业务或提现提交；
- 授权 Promise 成功或失败只会进入一次提现提交，避免重复创建申请；
- 小程序不接收、不保存也不上传任意 openId；
- 模板未配置时明确显示未开放，不使用占位模板 ID。

最新静态检查重点核对：

- `requestSubscribeMessage` 仅在微信小程序条件编译分支调用；
- 非微信端不会引用未定义的 `wx`；
- 业务授权单次最多三个模板、提现授权单次一个模板；
- 授权拒绝不会阻断真实业务接口；
- 提现申请不会因 Promise 成功和失败链路重复提交；
- 新接口和页面脚本不存在虚构业务数据。

边界：

- 不新增未注册页面；
- 不生成前端模拟二维码或占位二维码；
- 微信或文件存储未就绪时明确显示不可用；
- 健康报告不生成诊断、处方或虚构设备数据；
- 静态检查通过不等于微信开发者工具、真机、真实 Token、MinIO 和微信凭据 UAT 通过。

# 缺失接口与字段说明

以下结论仅依据本次收到的 App 工程及 `api/jk.js`。没有收到后端源码，因此未对服务端 Controller 做最终确认。

## 1. 推广素材列表

当前 `api/jk.js` 未发现推广素材列表接口。

当前处理：

- `pages/jk/promotion/material.vue` 使用本地 image2 素材展示。
- 复制文案、图片预览可以使用。
- 后续建议增加：

```text
GET jk/promotion/material/list
```

建议字段：

```json
{
  "id": 1,
  "materialType": "POSTER",
  "title": "邀请您加入九州康",
  "description": "共享健康事业新机遇",
  "imageUrl": "https://...",
  "copywriting": "推广文案",
  "sort": 1,
  "enabled": true
}
```

## 2. 动态推广海报保存

现有 `getJkPromotionQrcode()` 可返回二维码或分享路径，但 App 中未确认存在动态海报生成地址。

页面兼容字段：

- `posterUrl`
- `sharePosterUrl`
- `qrCodeBase64`
- `qrCodeUrl`
- `sharePath`
- `shareUrl`

如果没有 `posterUrl`，页面会提示“后端未返回可保存的动态推广海报”。建议由后端生成包含用户头像、昵称、邀请码和二维码的完整海报。

## 3. 团队成员详情与贡献记录

当前只发现：

```text
GET jk/team/summary
```

未发现独立成员详情和贡献记录接口。

当前处理：

- 列表页将成员数据通过路由参数传入详情页。
- 成员贡献记录只读取成员对象中的 `contributionRecords` 或 `commissionList`；没有字段时显示空状态。

建议增加：

```text
GET jk/team/member/{userId}
GET jk/team/member/{userId}/contribution/list
```

## 4. SKU 库存详情、批次和趋势

当前只发现库存汇总和库存流水：

```text
GET jk/stock/my
GET jk/stock/flow/list
```

未发现单独的 SKU 详情、批次、库存趋势接口。

当前处理：

- SKU 基本信息由库存列表通过路由参数传递。
- 批次与趋势在接口无字段时使用视觉占位，不作为真实业务数据。

建议增加：

```text
GET jk/stock/sku/{skuId}/detail
GET jk/stock/sku/{skuId}/trend
GET jk/stock/sku/{skuId}/batch/list
```

上线前应删除占位趋势，改用真实返回值。

## 5. 调拨接收方选择

当前创建调拨接口存在：

```text
POST jk/stock-transfer/create
```

但 App API 中未发现专门的“可调拨接收方列表”接口。

当前处理：

- 页面尝试复用 `jk/team/summary` 中的直属团队作为候选人。
- 没有团队列表时，显示“由系统按所属关系确定”。
- 选中成员后仅在存在成员 ID 时追加 `receiverUserId`。

需要后端确认 `create` 接口究竟是：

1. 创客 / 合伙人向所属区县代申请库存；或
2. 区县代向下级主动调拨库存。

如果属于第一种业务，后端应按有效上下级关系自动确定区县代，不应要求前端传接收方。

## 6. 银行卡管理与提现账户切换

当前未发现银行卡列表、新增、删除、设为默认等接口。

当前处理：

- 提现页尝试读取提现配置中的账户快照字段。
- “更换账户”和资金页“银行卡管理”点击后明确提示接口缺失。

建议增加：

```text
GET jk/payee-account/list
POST jk/payee-account/save
POST jk/payee-account/{id}/default
DELETE jk/payee-account/{id}
```

## 7. 商品分类与复杂筛选

`getJkProductCatalog(keyword)` 当前仅明确支持关键词参数，未确认分类、品牌、库存区间筛选。

当前处理：设计稿中的分类和筛选交互保留视觉效果，复杂筛选按钮会提示需要接口支持。

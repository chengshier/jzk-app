# 九州康小程序业务中心 UI 复刻与路由说明

## 一、本次处理原则

- 以原始 `app.zip` 为基础工程修改，不使用整张设计稿作为页面背景。
- 保留现有 API 调用、表单提交、审核、库存、佣金、资金、提现等业务逻辑。
- 按设计稿统一为 750rpx 设计基准，使用青绿色健康主题、轻卡片、弱阴影和大留白。
- 设计稿中缺少的核心插画使用 image2 生成，并作为独立素材放入 `static/jk-ui-v2/`。
- 新增页面已注册到 `pages.json`，首页、业务中心、列表、详情、申请及推广入口已接通。

## 三、首页与业务入口

`pages/user/index.vue` 已接入以下跳转：

- 未开通业务身份：进入身份申请入口。
- 已开通且未冻结：进入九州康业务中心。
- 我的服务区域：补充业务中心、我的团队、推广二维码、推广素材入口。
- 普通商城订单入口继续保留原 CRMEB 路由。

`pages/jk/business/index.vue` 根据主身份动态展示：

- 区县代：平台订货、下级调拨、库存、收益、资金、提现、团队。
- 创客 / 合伙人：我的调拨、库存、收益、资金、提现、团队。
- 冻结身份：入口点击时提示冻结原因，不直接放行业务操作。

- `components/jk/jk-product-row.vue`：商品列表行。
- `components/jk/payment-voucher-upload.vue`：付款凭证上传组件视觉重做。
